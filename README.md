## Features

- **Easy to Switch:** Allows you to tranfer data from other browsers installed on your device.
- **Based on ----:** Install extensions from the Chrome Web store and Firefox Addons.
- **AI Agent Compatibility:** Connect an AI agent (such as Claude, Gemini, ChatGPT, etc.) and allow the AI agent to inspect what you selected, highlighted or shared with the agent. Can be disabled in Settings.
- **Tor Network Support:** Connect to the Tor Network easily, and switch back to the standard internet with just the click of a button.
